Sakawa Guard

Paste any suspicious message (SMS, WhatsApp, email). A local AI on your device reads it first, private and offline-friendly. The cloud only steps in when your device cannot.

This build needs its Firebase keys. Add your web app config to docs/firebase-config.js, then reload.

    What to do

      Built with Firebase AI Logic hybrid inference for #BuildHybridAI 2026. On-device checks use Gemini Nano through the Chrome Prompt API; the fallback uses Gemini in the cloud. Text messages are analysed locally whenever possible, so they never have to leave your phone.
